# Exported .shortcut files / 导出的快捷指令文件

_Placeholder — no signed `.shortcut` file is published yet. / 暂未发布已签名的 `.shortcut` 文件。_

To contribute one / 如何贡献：

1. Build the shortcut with the steps in the main README. / 按主 README 搭好快捷指令。
2. **Remove your token first.** Replace it with an *Ask for Input* action or an *Import Question*, so the file contains `Bearer <INGEST_TOKEN>` only as a prompt. / **先删除你的令牌**，改成「要求输入」或「导入问题」，文件里不能带真实令牌。
3. Share → Options → *File* (or an iCloud link), and put the file here as `health-bridge.shortcut` or link it below. / 分享 → 选项 → 文件（或 iCloud 链接），放到本目录或贴链接。
4. Before publishing, import the file on another device and confirm no real token is inside. / 发布前在另一台设备导入检查，确认里面没有真实令牌。
